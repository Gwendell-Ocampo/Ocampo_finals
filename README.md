# System Integration

Nuxt application featuring an editable spreadsheet-style inventory grid powered
by Handsontable.

## Setup

Install dependencies:

```bash
npm install
```

Start the development server at `http://localhost:3000`:

```bash
npm run dev
```

## Editable data grid

After signing in, open **Editable Data Grid** from the navigation drawer. Click
a cell to edit its value or enter data in the blank row at the bottom. Changes
are held in memory and reset when the page is reloaded.

## Handsontable licensing

This project uses the `non-commercial-and-evaluation` license key, which
Handsontable documents for teaching, academic research, evaluation, testing,
and experimentation when the use is not intended for monetary compensation.
Check that your institution's and assignment's use qualifies under the current
[Handsontable license terms](https://handsontable.com/docs/vue-data-grid/license-key/)
before using it outside classroom evaluation. Commercial use requires an
appropriate commercial license key.
